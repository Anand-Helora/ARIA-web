# ARIA Web v1.1.2 — Ordre officiel du nommage

La carte compacte reste inchangée visuellement.

Le nom proposé suit désormais strictement cet ordre :

```text
Phase-Pôle-Site-Bloc-Étage-Numéro-Type-Discipline-Technique#Indice_Date_Description
```

Exemple :

```text
PEXP-PO1-CHJ-A-N00-001-PLA-EL-CFO#3_2026-04-28_Plan de puissance.pdf
```

Les boutons restent placés en bas de la carte :

- `Relancer l’analyse`
- `Retirer le document`
